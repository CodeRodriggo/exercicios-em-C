Repositório destinado às atividades, exercícios e práticas desenvolvidas na disciplina de Lógica e Linguagem de Programação Estruturada (LLPE) do curso de Engenharia de Software.

 Sobre o Projeto

Este repositório reúne os exercícios desenvolvidos durante as aulas de LLPE, utilizando a linguagem de programação C.

O objetivo é praticar e desenvolver os fundamentos da programação estruturada, trabalhando desde conceitos básicos até estruturas mais complexas.

Os exercícios são organizados de forma progressiva, permitindo acompanhar a evolução dos conhecimentos adquiridos durante a disciplina.
